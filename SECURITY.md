# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within Kairos, please report it privately.
Please do not open a public issue. Send security reports to the repository maintainers.
All security reports will be acknowledged and handled promptly.
