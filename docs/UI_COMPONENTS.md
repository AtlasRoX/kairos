# UI Component Catalog

Kairos provides accessible, styled React components built on Tailwind CSS.

## Components
- `Button`: Primary, secondary, danger, and ghost action buttons.
- `Input`: Standard input field with label and error state helper text.
- `Badge`: Status indicators for readiness scores and priority levels.
- `Dialog`: Accessible modal popup overlay with escape key dismissal.
- `Icons`: Scalable icon set leveraging Hugeicons and custom SVGs.
- `ThemeToggle`: One-click dark/light theme switch.
